How close does automatic NIR calibration get to published results?

We ran the NIR AutoML pipeline on 10 public NIR datasets (25 measured properties) and set every result next to the best published error we could find. All numbers are prediction errors (RMSE): lower is better.

Percentages in the calibration column are ensemble weights: each model's share of the final prediction. The pipeline picks them by greedily adding the model that most lowers the cross-validated error, 50 times, so the weights are multiples of 2% and add up to 100%. "Lower error" says how much lower the smaller error is than the larger one; "about equal" means within 1%.

Under the hood

The pipeline is an API with a web interface on top. Everything runs in containers, on a CPU or with a GPU.

Modelling Python 3.12, scikit-learn, NumPy, SciPy, Optuna for the search, LightGBM, PyTorch, TabPFN v2, SHAP for explanations
API and data FastAPI, Pydantic, SQLAlchemy, PostgreSQL 16, PDF reports with ReportLab and Matplotlib
Web interface and runtime Next.js, React, TypeScript, Tailwind CSS; Docker Compose
